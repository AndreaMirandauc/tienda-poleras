# Tienda de polera por WhatsApp

Sitio web estático para vender una polera y recibir pedidos personalizados por
WhatsApp. La persona puede seleccionar color, talla y cantidad antes de abrir
la conversación.

## Publicación con GitHub Pages

El sitio no requiere instalación ni compilación. GitHub Pages puede publicarlo
directamente desde la raíz de la rama `main`.

## Personalización rápida

- Número de WhatsApp: constante `WHATSAPP_NUMBER` en `script.js`.
- Nombre del producto: constante `PRODUCT_NAME` en `script.js`.
- Precio: constante `UNIT_PRICE` en `script.js` y texto visible en `index.html`.
- Marca, descripción, colores y datos de despacho: `index.html`.
