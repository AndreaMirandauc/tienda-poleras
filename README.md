# LOWY — tienda de prendas

Tienda estática optimizada para GitHub Pages. Incluye catálogo dinámico, filtros, buscador, selección de variantes, carrito persistente y checkout por WhatsApp.

## Editar productos

Los productos se encuentran al inicio de `script.js`, dentro de la constante `PRODUCTS`. Cada producto admite nombre, categoría, precio, stock, tallas, colores y estilo visual.

## Datos principales

- WhatsApp: `56966690359`
- Publicación: GitHub Pages
- Tecnologías: HTML, CSS y JavaScript sin dependencias

## Recomendación

Reemplazar las ilustraciones CSS por fotografías propias cuando estén disponibles. Mantener el stock y los precios actualizados en `script.js`.
