Preguntas frecuentes

Todo antes de comprar

¿La capucha se puede retirar?

Sí. Cada color incluye una imagen adicional que muestra la capucha separada para evidenciar su desmontabilidad.

¿Cómo funciona la vista 360°?

Arrastra horizontalmente la fotografía con el mouse o con el dedo. También puedes usar las flechas ubicadas debajo del visor.

¿Cómo se elige el número de WhatsApp?

Antes de enviar el pedido, seleccionas retiro o zona de despacho. La página abre automáticamente el contacto correspondiente.
