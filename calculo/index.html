Cómo agregar un nuevo PDF

Esta página funciona con GitHub Pages. Para subir una solución nueva:

  1. Entra al repositorio salecl/tienda-poleras.
  2. Abre la carpeta calculo/soluciones/.
  3. Sube tu PDF, por ejemplo: capitulo-01-ejercicio-05.pdf.
  4. Edita calculo/soluciones.json y agrega una ficha con el enlace al PDF.
  5. Guarda el cambio. GitHub Pages se actualizará solo.

Estructura recomendada

calculo/
  index.html
  styles.css
  app.js
  soluciones.json
  soluciones/
    capitulo-01-ejercicio-05.pdf
    capitulo-02-ejercicio-12.pdf
